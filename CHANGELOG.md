# Haul 2026.10.19.1

**A small fix for WoW: Forever.**

- **Fixed: getting stuck on an empty corpse.** Forever now opens a loot window even when a corpse has nothing on it. With Ultra fast loot on, that empty window stayed open out of sight and kept your character in the looting state until you moved. Haul now closes an empty window by itself.

**Tip for WoW: Forever: install Auctionator for auction prices.** Without an auction addon, Haul can only value your loot at vendor prices, which makes most hauls look a lot sadder than they are. Install the Forever version of Auctionator, run a scan at the Auction House so it knows current prices, then pick Auctionator under Price source in Haul's settings. If Auctionator was already installed the first time you ran Haul, it's picked for you.

Nothing else changes. Tracking, pricing and sessions work exactly as before.
